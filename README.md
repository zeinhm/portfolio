# zeinhm.dev

Personal portfolio of Zein Hammad Marhabah, a software engineer based in Jakarta, Indonesia.

Live: https://www.zeinhm.dev

## Stack

Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS v4, shadcn/ui, next-themes.

## Develop

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint
```

## Content

Almost all site copy lives in `lib/data.ts` (SITE config, SKILLS, WORK_HISTORY, USES).
